# deeptech.family

Перенос текущего сайта deeptech.family на Next.js без расширения согласованного scope.

## Что входит
- визуально близкий перенос публичного сайта;
- тексты, навигация и подтверждённые assets;
- адаптивность desktop/mobile;
- нейтральные международные формулировки вместо BRICS / BRICS+;
- footer и контакты;
- предоставленные юридические документы;
- глобальный canvas GraphNetwork;
- переключение языка и локализованный контент;
- финальная визуальная сверка с оригиналом.

## Что не входит
- CRM;
- CMS / визуальный редактор;
- микросервисы;
- SEO-продвижение как отдельная услуга;
- новые внешние интеграции и автоматизация заявок;
- несогласованный редизайн.

## Стек
- Next.js
- React
- TypeScript
- CSS
- локальный Inter
- SVG assets оригинального сайта

## Структура
- `app/` — страницы, metadata, legal routes и стили;
- `components/` — Header, Footer, GraphNetwork, локализация и секции;
- `public/assets/icons/` — подтверждённые SVG;
- `public/assets/fonts/` — локальный Inter;
- `docs/` — аудит и документация переноса.

## Локальный запуск

```bash
npm install
npm run dev
```

Открыть `http://localhost:3000`.

Основная рабочая ветка после завершения проверки — `main`.

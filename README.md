# deeptech.family

Проект переноса текущего сайта deeptech.family.

## Текущий согласованный scope
На этом этапе выполняется только перенос существующего сайта.

В работу входит:
- перенос текущих страниц и визуальной структуры;
- перенос текстов, изображений и ссылок;
- замена упоминаний БРИКС на нейтральные формулировки про международное сотрудничество;
- обновление footer по данным заказчика;
- добавление предоставленных политик;
- сохранение адаптивности;
- проверка основных страниц и ссылок после переноса.

Не входит в текущий этап:
- CRM;
- CMS/визуальный редактор;
- микросервисная архитектура;
- SEO-продвижение по ключевым словам;
- новые интеграции Telegram/WhatsApp/email;
- переработка бизнес-логики.

## Принцип работы
1. Определяем, что нужно изучить для следующего шага.
2. Изучаем текущий сайт/исходники.
3. Реализуем перенос.
4. Коммитим изменения в GitHub.
5. Проверяем.
6. В конце даём команды для синхронизации проекта на локальный ПК.

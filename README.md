# deeptech.family

Frontend проекта на Next.js. Архив сайта от заказчика ещё не получен, поэтому после его получения потребуется сверить реализацию с архивом перед передачей заказчику.

## Запуск

```bash
npm ci
npm run dev
npm run build
npm run start
```

`npm run dev` запускает сайт для разработки на `http://localhost:3000`. Сборка и запуск production-версии выполняются через `npm run build` и `npm run start`.

## Структура

- `app/` — страницы и стили;
- `components/` — компоненты сайта и локализованный контент;
- `lib/` — метаданные страниц и настройки языка и cookies;
- `public/assets/` — шрифты и SVG-иконки.

Интерфейс поддерживает русский, английский, испанский, арабский и китайский языки. Для арабского включается направление текста RTL.

Форма обратной связи не отправляет заявки, а кнопки каналов связи отключены до настройки каналов. Страница Privacy Policy — placeholder; утверждённый текст ещё не предоставлен.

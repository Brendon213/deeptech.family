# deeptech.family

Новая версия сайта deeptech.family.

## Цель
Перенос текущего сайта на управляемую архитектуру с CMS, SEO/индексацией, аналитикой и системой приема заявок.

## Ключевое решение
На старте используем модульную архитектуру, а не набор микросервисов ради самого подхода.

CMS отвечает за редактирование сайта. Полноценная CRM не нужна, пока нет задачи управлять клиентами и сделками.

## Архитектура
- apps/web — публичный Next.js сайт;
- apps/cms — CMS;
- services/leads — заявки и интеграции;
- infra — инфраструктура;
- docs — проектная документация.

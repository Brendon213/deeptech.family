# Как добавлять и редактировать статьи

Статьи на рабочем сайте читаются прямо с Beget из папки:

`~/deeptech.family/content/articles/`

GitHub для ежедневного добавления и редактирования статей не нужен.

Раздел открывается по адресу `https://deeptech.family/articles`; другие языки:
`/en/articles`, `/es/articles`, `/ar/articles`, `/zh/articles`.

## Добавить статью через файловый менеджер Beget

1. Откройте в Beget файловый менеджер.
2. Перейдите в `deeptech.family/content/articles/`.
3. Скопируйте файл `_template.md`.
4. Назовите копию, например `my-topic.ru.md`.
5. Измените поля между двумя строками `---`:
   - `title` — название статьи;
   - `description` — краткое описание для карточки и поисковиков;
   - `slug` — адрес статьи после `/articles/`, например `my-topic`;
   - `date` — дата в формате `ГГГГ-ММ-ДД`;
   - `category` — категория, строку можно удалить;
   - `language` — `ru`, `en`, `es`, `ar` или `zh`.
6. После второго `---` напишите текст статьи.
7. Сохраните файл.

Новая или изменённая статья появляется на сайте без пересборки и без нового `beget-X`.
Перезапуск Node-приложения для изменения текста статьи не требуется.

## Формат текста

- Обычные абзацы разделяются пустой строкой.
- `## Заголовок раздела` — заголовок второго уровня.
- `### Подзаголовок` — заголовок третьего уровня.
- `[текст ссылки](https://example.com)` — ссылка.
- `- Пункт` — пункт списка.

Заголовок первого уровня `#` внутри текста не нужен: страница берёт его из `title`.

## Правила имени файла

Имя файла должно совпадать со `slug` и языком:

`slug.language.md`

Пример:

`my-topic.ru.md`

и внутри:

`slug: "my-topic"`
`language: "ru"`

Используйте для `slug` только маленькие латинские буквы, цифры и дефисы.

## Перевод статьи

Скопируйте существующий файл, например:

`my-topic.ru.md` → `my-topic.en.md`

Переведите `title`, `description`, `category` и основной текст, замените `language` на `en`, а `slug` оставьте тем же.

## Изменить статью

Откройте нужный `.md`-файл на Beget, измените нужные поля или текст и сохраните.
Изменения будут читаться сайтом при следующем открытии страницы.

## Удалить статью

Удалите соответствующий `.md`-файл из `content/articles/`.
Для удаления статьи на всех языках удалите все файлы с тем же `slug`.

При смене `slug` меняется URL статьи. Для уже опубликованных материалов лучше `slug` не менять.

Не помещайте в статьи пароли, токены и личные данные: содержимое публикуется открыто.

## Для разработчика

В GitHub папка `content/articles/` остаётся как исходный набор и fallback для сборки.
На Beget рабочие статьи должны храниться отдельно от `app`:

`~/deeptech.family/content/articles/`

Приложение сначала ищет `ARTICLES_DIR`, затем внешнюю папку `../content/articles`, затем локальную `content/articles`.
Это позволяет обновлять папку `app`, не затирая статьи заказчика.

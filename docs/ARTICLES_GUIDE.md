# Как добавлять и редактировать статьи

Статьи лежат в папке `content/articles/`. Один файл `.md` — одна языковая версия статьи. Раздел открывается по адресу `https://deeptech.family/articles`; другие языки: `/en/articles`, `/es/articles`, `/ar/articles`, `/zh/articles`.

## Добавить статью

1. Откройте в GitHub папку `content/articles/` и файл `_template.md`. Скопируйте его содержимое.
2. В папке `content/articles/` нажмите **Add file → Create new file**. Введите имя `my-topic.ru.md` (замените `my-topic` на короткое название латинскими буквами, через дефис). Вставьте скопированный шаблон.
3. Измените поля в самом начале, между двумя строками `---`:
   - `title` — название на карточке и странице статьи; также используется в заголовке браузера.
   - `description` — короткое описание на карточке и для Google/Яндекса. Поисковик может показать собственный фрагмент текста.
   - `slug` — часть URL после `/articles/`. Например, `my-topic` даст `https://deeptech.family/articles/my-topic`. Должен совпадать с началом имени файла; только маленькие латинские буквы, цифры и дефисы.
   - `date` — дата публикации в формате `ГГГГ-ММ-ДД`, в кавычках.
   - `category` — необязательная подпись на карточке; можно удалить всю строку.
   - `language` — язык статьи: `ru`, `en`, `es`, `ar` или `zh`. Он должен совпадать с окончанием имени файла перед `.md`.
4. После второго `---` напишите основной текст. Обычные абзацы разделяйте пустой строкой. `## Заголовок раздела` создаёт заголовок второго уровня, `### Подзаголовок` — третьего. Заголовок первого уровня (`#`) в тексте не нужен: его сайт берёт из `title`. Ссылка: `[текст ссылки](https://example.com)`. Список: строка `- Пункт` для каждого пункта.
5. Нажмите **Commit changes** в ветке `main`. GitHub запустит сборку Beget. После успешной сборки установите новый `beget-X` на сервер по действующей инструкции развёртывания. Сам коммит пока не меняет работающий сайт.

Готовый файл для копирования: [`content/articles/_template.md`](../content/articles/_template.md). Файлы с начальным `_` не публикуются.

## Перевод статьи

Скопируйте существующий файл: например, `my-topic.ru.md` → `my-topic.en.md`. Переведите `title`, `description`, `category`, основной текст и замените `language` на `en`. Поле `slug` **оставьте тем же**: тогда версии будут связаны. Английская версия появится по `/en/articles/my-topic`. Аналогично для `es`, `ar`, `zh`. Если перевода пока нет, список на другом языке покажет русскую статью с отметкой языка и ссылкой на русский адрес.

## Изменить или удалить

Чтобы изменить статью, откройте её файл в GitHub, нажмите значок карандаша, измените нужные строки и сохраните через **Commit changes**. Чтобы удалить, откройте файл и выберите **Delete file**, затем подтвердите коммит. Для удаления статьи на всех языках удалите все файлы с её `slug`. В обоих случаях дождитесь успешной сборки и обновите сайт на Beget. При смене `slug` меняется URL; старые ссылки перестанут работать. Если статья уже опубликована, лучше сохранять `slug`.

Дата `date` остаётся датой публикации; при исправлении опечатки менять её не нужно. Не помещайте пароли, токены и личные данные в файлы: тексты публикуются открыто.

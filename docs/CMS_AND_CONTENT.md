# CMS и управление контентом

## Цель
Позволить заказчику редактировать сайт без изменения кода и без ручной перезаливки всего проекта.

## Основная модель

### Page
- title
- slug
- status
- blocks
- seo
- created_at
- updated_at

### SEO
- meta_title
- meta_description
- canonical
- og_title
- og_description
- og_image
- robots_index
- robots_follow

### Reusable blocks
Повторно используемые элементы:
- footer;
- контакты;
- CTA;
- логотипы;
- юридические ссылки.

## Публикация
Редактор:
1. меняет контент в CMS;
2. сохраняет draft;
3. смотрит preview;
4. публикует;
5. CMS вызывает revalidation;
6. Next.js обновляет только нужную страницу.

Это позволяет исправить букву, запятую или изображение без ручной пересборки всего сайта.

## Ограничения редактора
Не давать свободный HTML/JS без необходимости.

Правильная модель — готовые компоненты и редактируемые поля.

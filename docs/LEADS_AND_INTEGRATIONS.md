# Заявки и интеграции

## Поток

```text
Форма
 -> validation
 -> anti-spam
 -> save lead
 -> notifications
      -> Telegram
      -> Email
      -> WhatsApp
```

## Минимальные поля
- имя;
- телефон/email;
- сообщение;
- страница-источник;
- UTM;
- дата;
- статус доставки уведомлений.

## Telegram
Через Bot API.

## Email
Через SMTP или транзакционный email-сервис.

Для нормальной доставляемости понадобятся SPF/DKIM/DMARC.

## WhatsApp
Не использовать неофициальную автоматизацию личного WhatsApp.

Нормальные варианты:
- WhatsApp Business Platform;
- Cloud API;
- официальный BSP;
- интеграция существующей CRM.

## Надежность
- сначала сохранять заявку;
- потом отправлять уведомления;
- ошибки одного канала не должны терять заявку;
- retry;
- логирование;
- rate limit;
- honeypot / CAPTCHA при необходимости.

# Что нужно получить для переноса

1. Доступ к исходникам текущего сайта, если они есть.
2. Если исходников нет — подтверждение, что перенос делаем по публичной версии сайта.
3. Полный список страниц, если есть скрытые или не связанные меню.
4. Политики, которые нужно добавить.
5. Номер телефона для footer.
6. Подтверждение текста:
   - LLC Global trade and investment solutions.
7. Уточнение, нужно ли переносить существующие формы в текущем виде.
8. Доступы к хостингу/домену понадобятся только на этапе публикации.

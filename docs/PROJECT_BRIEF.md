# DeepTech Family — Project Brief

## Цель
Перенести сайт deeptech.family на новую архитектуру с управляемым контентом, сохранением SEO-потенциала и возможностью точечного редактирования без участия разработчика.

## Основные изменения
- Убрать упоминания БРИКС и заменить их на нейтральные формулировки про международное сотрудничество.
- Сохранить существующий смысл и структуру страниц там, где не согласован редизайн.
- Добавить юридические документы, которые предоставит заказчик.
- Обновить footer:
  - LLC Global trade and investment solutions;
  - номер телефона;
  - остальные реквизиты после уточнения.

## Контент
Заказчик должен иметь возможность самостоятельно:
- исправлять текст;
- менять изображения;
- менять кнопки и ссылки;
- редактировать SEO-поля;
- включать/выключать блоки;
- менять порядок блоков;
- работать через визуальную/структурную CMS.

## CRM
Полноценная CRM на первом этапе не нужна.

Задача заказчика сейчас — редактирование контента и получение заявок. Это задача CMS.

CRM имеет смысл добавлять позже, если понадобятся:
- карточки клиентов;
- сделки;
- статусы лидов;
- менеджеры;
- история коммуникаций;
- автоматические воронки.

## Заявки
Форма сайта должна:
1. принимать заявку;
2. сохранять ее;
3. отправлять уведомление в Telegram;
4. отправлять уведомление на email;
5. поддерживать WhatsApp через официальный API или провайдера.

## SEO и аналитика
Нужно предусмотреть:
- Google Search Console;
- Яндекс Вебмастер;
- Google Analytics 4;
- Яндекс Метрику;
- sitemap.xml;
- robots.txt;
- canonical;
- schema.org;
- Open Graph;
- корректные title/description;
- SEO-страницы под предоставленные ключевые слова;
- server-side rendering / static generation.

Важно: техническая SEO-настройка может обеспечить корректную индексацию, но не гарантирует позиции в топе по конкретным запросам.

## Пока не определено
- список ключевых слов;
- регионы продвижения;
- список всех страниц;
- языки сайта;
- WhatsApp-провайдер;
- текущий хостинг;
- доступы к домену/DNS;
- список политик;
- роли редакторов;
- требования к хранению персональных данных.

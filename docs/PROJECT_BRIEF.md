# DeepTech Family — перенос сайта

## Цель
Перенести публичную версию deeptech.family в новый репозиторий максимально близко по структуре, визуалу и поведению без расширения согласованного объёма работ.

## Входит
- страницы и секции текущего сайта;
- тексты, ссылки и навигация;
- подтверждённые шрифты и SVG assets;
- responsive desktop/mobile;
- интерактивный canvas-фон;
- языковое переключение после проверки списка локалей оригинала;
- нейтральные международные формулировки вместо BRICS / BRICS+;
- footer:
  - LLC Global trade and investment solutions;
  - +7 953 282-22-22;
  - office@deeptech.family;
  - @go_to_market_IT;
- юридические страницы после получения утверждённого текста;
- финальная визуальная и функциональная сверка.

## Не входит
- CRM;
- CMS;
- визуальный редактор;
- микросервисы;
- отдельное SEO-продвижение;
- новые внешние интеграции;
- несогласованный редизайн.

## Принцип
Оригинальный публичный сайт — визуальный эталон. Сначала достигается максимально близкий перенос; любые новые функции добавляются только отдельно.

# SEO, GEO, аналитика и AI discoverability

## Техническая SEO
- SSR/SSG;
- уникальные title и description;
- корректная структура H1-H3;
- canonical;
- sitemap.xml;
- robots.txt;
- 301 redirects;
- alt для изображений;
- оптимизация изображений;
- Core Web Vitals;
- schema.org;
- Open Graph;
- корректные 404/410.

## Индексация
После переноса:
- Google Search Console;
- Яндекс Вебмастер;
- отправка sitemap;
- проверка coverage/indexing;
- проверка редиректов;
- контроль crawl errors.

## Аналитика
- Google Analytics 4;
- Яндекс Метрика;
- отправка формы;
- успешная заявка;
- клик по Telegram;
- клик по WhatsApp;
- клик по email;
- клик по телефону;
- UTM.

## Работа с ключевыми словами
После получения семантики:
1. кластеризация;
2. привязка кластеров к страницам;
3. выявление недостающих страниц;
4. title/H1/description;
5. внутренняя перелинковка;
6. проверка каннибализации.

Нельзя просто добавить все ключи на одну страницу.

## GEO
Если речь о географической релевантности:
- реальные контактные данные;
- Organization/LocalBusiness schema только когда это соответствует бизнесу;
- отдельные региональные страницы при реальной необходимости;
- hreflang только для существующих языковых версий.

## AI discoverability
- доступный HTML;
- понятная структура страниц;
- About / Services / Contacts;
- schema.org;
- стабильные URL;
- FAQ там, где он реально нужен;
- понятные сущности и названия услуг.

llms.txt можно добавить как экспериментальный файл, но он не заменяет SEO и не гарантирует попадание в ответы ИИ.

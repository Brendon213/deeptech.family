# Визуальный аудит deeptech.family

Дата: 2026-09-23

Источник: публичная версия https://deeptech.family/

## Статус точности

Аудит разделён на три уровня:

- **Подтверждено** — данные и поведение, которые можно надёжно определить по текущей публичной странице.
- **Оценка** — визуальные параметры, которые видны по композиции, но не могут считаться точными без CSS/DevTools.
- **Требует извлечения из оригинала** — шрифты, точные HEX/RGB, пиксельные размеры, breakpoint-значения, исходные изображения и анимационные параметры.

Текущий сайт определяется как проект на Tilda. Публичная страница доступна поисковому обходу, но прямое извлечение CSS/визуальных токенов ограничено. Поэтому ниже не выдаются придуманные значения как "точные".

## Подтверждено визуально

## Точные значения

Точные HEX/RGB **не подтверждены**.

Нельзя считать текущие переменные из нашего `app/globals.css` цветами оригинального сайта.

Перед пиксельным переносом нужно извлечь:
- background страницы;
- primary text;
- secondary text;
- card background;
- border;
- dark section;
- primary button;
- hover/focus states.

# 13. Размеры и отступы

## Подтвержденный принцип

Дизайн использует:
- крупные вертикальные интервалы между смысловыми секциями;
- ограниченную ширину основного контента;
- крупный H1;
- заметно меньшие H2/H3;
- повторяемые интервалы в карточках;
- широкую desktop-сетку.

## Что нельзя честно считать точным без CSS

Пока не подтверждены:
- max-width контейнера;
- высота Header;
- desktop padding секций;
- mobile padding;
- gap между колонками;
- border-radius;
- размеры кнопок;
- line-height;
- breakpoint.

Все такие значения в текущем `globals.css` являются **каркасными**, а не копией оригинала.

- шрифт;
- цвета;
- размеры;
- отступы;
- радиусы;

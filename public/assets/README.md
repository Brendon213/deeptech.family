# Assets

Структура для ресурсов текущего сайта:

- public/assets/images — изображения и фоновые элементы;
- public/assets/icons — иконки;
- public/assets/fonts — локальные шрифты, если они будут нужны после аудита текущего сайта.

На этапе точного переноса сюда будут добавлены реальные assets из публичной версии или исходников сайта.
